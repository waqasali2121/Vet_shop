2 How to Add a Medicine (Catalog Entry)

Adding stock quantities to your inventory requires a two-step flow: first creating the product card (catalog definition), and second recording the purchase receipt to bind quantities and actual batch prices.

Step 2.1: Add the Supplier

Before adding stock, ensure the medicine's distributor exists:

  1. Navigate to Purchases -> Suppliers.
  2. Click New Supplier.
  3. Enter the Supplier Name (e.g. ICI Pakistan or Star Laboratories) and a valid **Phone Number**.
  4. Click Save Supplier.

Step 2.2: Define the Product (Medicine Card)

  1. Navigate to Inventory -> Products on the sidebar.
  2. Click Add Product (top-right).
  3. Fill in the core parameters:
    • Name: Medicine generic/brand name (e.g. Oxytetracycline 10%).
    • Category: Select from the list (e.g., Injections, Antibiotics, etc.).
    • Brand: Select the manufacturer.
    • Unit: Select the packaging unit (e.g., Vial, Box, Piece).
    • Retail Price (selling price): The price you will charge the customer.
  4. Ensure **Track Batch** and **Track Expiry** toggles are enabled.
  5. Click Save Product.

3 Adding Stock Quantities (Purchases)

Do not change stock levels manually. Instead, log the supplier's invoice. This ensures purchase ledgers and batch details remain accurate.

Recording the Supplier Invoice

  1. Go to Purchases -> New Purchase.
  2. Select the **Supplier** and input the **Invoice/Reference Number**.
  3. In the product search, look up the medicine you created in Section 2.
  4. Input the exact details from your vendor invoice:
    • Quantity: Number of units bought.
    • Unit Cost (Purchase Price): Price paid per unit.
    • Batch Number: The batch identifier printed on the vial or packaging.
    • Expiry Date: The official expiry date of this specific batch.
  5. Select **Payment Details** (Cash, Bank, or Credit/Due balance).
  6. Click Submit Purchase.

FEFO Engine (First Expire, First Out): The system automatically assigns POS checkout transactions to the earliest expiring batch of that product. Expired batches are automatically blocked from checkout.

4 Operating the POS Terminal

The POS terminal is built for speed and precision. Cashiers can complete sales in seconds.

Step 4.1: Open Cash Register

Before making any sales, you must open the register session:

  1. Go to Cash Register.
  2. Input the **Opening Cash** amount currently in the drawer.
  3. Click **Open Session**.

Step 4.2: Creating a Checkout Ticket

  1. Navigate to the **POS** screen on the sidebar.
  2. Select the Customer (defaults to Walk-in Customer).
  3. Select medicines: Either scan the barcode or type the product name in the search bar.
  4. The cart will populate. Select the quantity.
    • Note: The system blocks transactions that exceed available physical stock.
  5. Select the payment method: **Cash**, **Card**, or **Credit** (Credit is only allowed for registered farmers/dealers, not walk-ins).
  6. Click **Process Payment**.

Step 4.3: Close Register at End of Shift

  1. Go to Cash Register.
  2. Count your cash in the physical drawer and input it in **Actual Closing Cash**.
  3. The system calculates differences or discrepancies, logs them, and closes the session.

5 Employee Access Roles

The system uses strict roles to limit exposure to financial records and administrative changes:

Role Permissions Restrictions
OWNER Full system control, reports, settings, delete permissions. None.
MANAGER Manage products, log purchases, view registers, process returns. Cannot change system settings or modify user profile roles.
INVENTORY View catalog, record purchases, adjust stock, manage batches. Cannot view cash registers, margins, profits, or sales reports.
CASHIER Run the POS, create bills, close registers, search items. Cannot void transactions, modify historical stock, or view costs.
